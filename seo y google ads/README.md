## 4. Сознательные отклонения от брифа

1. **K4 разделена на Premium и Económico.** Бриф сам говорит, что клиент за 150 € и за 1.000 € —
   разные люди. Económico (GLC, A200) рекомендую держать **на паузе**: 30 % комиссии от
   150–200 €/день не окупает клик по 1–2 €. Собрана для полноты (бриф: группа на каждую машину).
2. **Volkswagen нет в K3.** Единственная машина = Golf R, брендовые запросы «alquilar volkswagen»
   — это Sixt‑аудитория. Golf R живёт в K4.
3. **Модельные запросы убраны из K3 минус‑словами групп** (911, cayenne, g63, rs3, velar…), чтобы
   брендовые и модельные группы не конкурировали за одни показы.
4. **Английские ключи** добавлены в брендовые/модельные группы; отдельная EN‑группа только в K2.
5. **Депозит в текстах — «Fianza desde 2.000 €»**, у G63 сумма не указана: по прайсу партнёра
   у G63 залог 5.000 €, а в docx стоит 2.000 € для всех. Подтвердите, и я поправлю тексты.
6. **K7 Remarketing не собран** — нужны аудитории GA4, а им нужно 30 дней данных.
7. **Условия аренды** — подтверждены 03.09: **18+, только права без стажа, 150 км/день**
   (единицу «в день» я предположил — поправьте, если это лимит на всю аренду). Добавлены в
   заголовки, описания и callouts всех кампаний: «Desde 18 años con carnet»,
   «150 km/día incluidos». Страховка, франшиза, цена доп. км — по‑прежнему не упоминаются.
8. **Флот 13 машин (04.09, скрин папок).** Убраны Macan, 718 Spyder, Clio, C220d Cabrio и обе мото;
   добавлены Lamborghini Urus, Audi RS6 Avant, Audi RS Q3. Цены Urus и RS6 **выведены** от G63 по
   вашему правилу (Urus чуть выше: 1.100/1.900/3.000/6.500/13.000; RS6 чуть ниже:
   900/1.600/2.500/5.500/11.000) — правьте в `fleet.json`, всё пересоберётся. RS Q3 — 450 €/день по
   прайсу партнёра от 17.07. Две папки 911: «Porsche 911» = 992 Cabrio (800 €), «911 991» =
   Carrera S (700 €) — это моё допущение. Залог Urus и RS6 не подтверждён — в их объявлениях
   сумма не указана. Lamborghini получил свою группу в Por Marca и страницу `/flota/lamborghini`;
   Huracán/Aventador и все убранные модели — в минус‑словах, чтобы не платить за чужой спрос.

## 5. Порядок запуска — менять нельзя

1. **Программист:** редизайн по docx + `TZ-tracking-serresdrive-ES.md` + `fleet.json`.
   От вас ему нужны: номер WhatsApp Serres Drive, телефон, email, фото 16 машин, ответ по залогу G63.
2. **Аккаунт Google Ads.** Рекомендую **отдельный аккаунт** для Serres Drive под MCC 6976191925:
   отдельная карта (сбои карты wrap‑центра на порогах автоплатежей не будут гасить прокат),
   отдельные конверсии и отчёты, отдельная верификация рекламодателя. Создать в UI: MCC → Аккаунты →
   «+» → Новый аккаунт → привязать карту. Затем в `google-ads-api-setup/.env` поменять
   `GOOGLE_ADS_CUSTOMER_ID` на новый ID (а `LOGIN_CUSTOMER_ID` — на MCC 6976191925).
   Если решите строить в текущем аккаунте 2746010209 — ничего менять не надо.
3. **Токен API.** В терминале:
   ```
   cd "/Users/leonidlebedev/Desktop/GOOGLE ADS/google-ads-api-setup"
   python3 generate_refresh_token.py
   ```
   Откроется браузер → войти как ads.serres.01@gmail.com → токен сам запишется в `.env`.
   Чтобы не повторять каждые 7 дней: Google Cloud Console → APIs & Services → OAuth consent
   screen → **Publish app**.
4. **GA4.** analytics.google.com → создать свойство «Serres Drive» (Испания, EUR) → поток Web
   `serresdrive.com` → скопировать `G-…` → программисту в ТЗ, раздел 0.
   **Не** использовать `G-1K6FYZ99GN` — это свойство wrap‑центра.
5. **Конверсии.** `python3 setup_serresdrive_conversions.py` → печатает `AW-…` и три label →
   программисту в ТЗ, раздел 0.
6. **Проверка трекинга** по чеклисту ТЗ (раздел 10). В UI: Google Ads → Инструменты → Связанные
   аккаунты → GA4 → связать; Объявления → Объекты → Адреса → привязать Google Business Profile.
7. **Объёмы.** `python3 pull_keyword_ideas_serresdrive.py` → `keyword-volumes.csv`. Ключи с нулём
   показов за 12 мес. удалить из конфига (или оставить — они не стоят денег).
8. **Сборка.** `python3 build_serresdrive_all.py` — сам проверит, что все 26 посадочных живы,
   и создаст всё в статусе PAUSED. Проверка в UI по чеклисту `campaigns/campaigns.md` (Step 5 и
   5.1: AI Max, DSA, автоактивы, broad match, партнёры — всё OFF; автоприменение рекомендаций OFF).
9. **Включение:** кампании → группы → объявления. Económico оставить на паузе.
10. **Первые 14 дней:** отчёт «Поисковые запросы» ежедневно, мусор — в минус‑слова.
    После **30 конверсий** — переход на tCPA (бриф 3.6). Через 30 дней — аудитории и K7.

## 7. Запасной путь без API: Google Ads Editor

Если токен/доступ подведут: Google Ads Editor → Account → Import → From file → файлы из
`ads-editor/` **по порядку номеров** (01 → 08). В диалоге импорта Editor просит сопоставить
колонки — названия колонок совпадают с его экспортом, обычно всё подхватывается автоматически.
Гео (радиус 40 км, исключение стран), языки и стратегию ставок проверить вручную после импорта:
CSV‑импорт Editor ставит их не всегда.
